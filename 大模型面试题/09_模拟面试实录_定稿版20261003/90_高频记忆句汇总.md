# 高频记忆句汇总（19 条）

> 提取自《DataPilot 模拟面试》2026-10-05，速记背诵用；完整上下文见同目录各题文件。

---


1. **我是做 Agent / LLM 应用工程的，重点不是“把模型接上”，而是把工具、状态、安全和评测真正做成系统。**
2. **95% 是固定基准的历史回归结果，不是生产环境准确率。**
3. **评分器负责稳定回归，不等于完整的语义裁判。**
4. **先冻结基准，再让 Agent 串行取证；结论先绑定证据，最后才生成正文。**
5. **Run 内先保证同一个事实和配置基准，新变化留给下一次 Run。**
6. **历史语义可以复用，历史数据必须重新证明。**
7. **事实状态不靠聊天历史保存，聊天历史只是每轮给模型看的一个视图。**
8. **结论有证据、材料要干净、落到正文还要再核一遍。**
9. **当前固定修一次，不靠堆重试换正确率；第二次还错就 partial。**
10. **不是看 SQL 像不像 SELECT，而是看 AST 里到底允许它做什么。**
11. **敏感字段由用户显式配置，Data Gateway 在数据进入模型之前统一遮蔽。**
12. **脱敏要发生在模型之前，而不是答案之前。**
13. **模型可以写分析逻辑，但不能决定它获得什么系统权限。**
14. **17 条全拦截只能证明已覆盖场景没回归，不能证明不存在未知绕过。**
15. **安全边界不自动放宽，可修复错误给模型重试路径。**
16. **模型只能使用安全策略，不能修改安全策略。**
17. **Schema 告诉模型数据长什么样，DataLink 补的是这些字段在业务里是什么意思、应该怎么连。**
18. **系统能验证这个数字是不是查出来的，但不一定能验证你是不是查对了业务指标。**
19. **语义错误未必能自动判，但要做到可追踪、可修订、可沉淀。**

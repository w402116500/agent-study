### 我的原回答

**⚠️ 原话未完整取回。**

面试官您好，我目前是软件工程本科在读，主要方向是 AI Agent 和大模型应用开发。

我最近主要独立做了两个项目。第一个是 DataPilot，是一个面向结构化数据分析的 Agent，用户可以直接用自然语言对 CSV、SQLite 和 MySQL 做查询和分析。我在这个项目里重点做了 Agent 工具循环、上下文和会话记忆、SQL 与代码执行安全，以及基于证据的答案校验，并且自己做了一套固定评测来验证系统稳定性。

第二个项目是 Enterprise RAG，主要面向企业知识库问答。我重点解决的是文档切分后证据不完整的问题，通过结构化分块、父子上下文补全和混合检索来提升召回效果，同时也做了固定题集的对照评测。

我做这两个项目时比较关注的一点是，不只是把 Demo 跑起来，而是会继续考虑评测、失败处理、安全边界和可复现性。所以我目前也比较希望往 Agent 应用开发、大模型应用工程这类岗位发展。

### 关键修正

开场自我介绍不要把简历逐条念一遍，控制在 45～60 秒，重点让面试官迅速知道三件事：你是谁、你主要做什么方向、你最值得继续追问的项目是什么。

DataPilot 和 Enterprise RAG 都可以提，但 DataPilot 应该成为主线，因为后续绝大多数深挖都从它展开。评测数字可以点到为止，不要在第一分钟堆太多指标。

### 修正版口述答案

我目前是软件工程本科在读，求职方向主要是 Agent 应用开发和大模型应用工程。

最近我主要独立做了两个项目。一个是 DataPilot 企业数据分析 Agent，面向 CSV、SQLite 和 MySQL，让用户通过自然语言完成任务规划、数据查询、分析和带证据回答。我在里面重点做了 Agent 工具循环、上下文与会话状态、SQL 和 Python 执行安全，以及最终答案的证据校验。

另一个是 Enterprise RAG，主要做企业多格式文档的解析、结构感知分块、混合检索、Rerank 和带来源回答。

我比较关注的不只是 Demo 能不能跑起来，而是系统能不能被评测、被审计，以及遇到失败时有没有明确的安全边界和降级路径。

### 一句话记忆

**我是做 Agent / LLM 应用工程的，重点不是“把模型接上”，而是把工具、状态、安全和评测真正做成系统。**

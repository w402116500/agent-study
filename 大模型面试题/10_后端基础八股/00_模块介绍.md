# 后端基础八股介绍

> 本模块补齐大模型/Agent 应用岗位面试中常被问到的后端基础八股，共 45 题，分六个板块：后端与部署（BE×6）、数据库与 SQL（DB×10）、Redis 缓存（RED×7）、Docker 部署与沙箱（DOCK×8）、网络基础（NET×8）、操作系统（OS×6）。
>
> **来源**：BE / DB / RED / DOCK 共 31 题复制收录自《Agent应用开发个人面经_完整版》（20261002 新版简历配套整理，20261002 版），内容未改写；NET / OS 共 14 题为本模块新撰（2026-10-06），格式对齐个人面经，并绑定 DataPilot / Enterprise RAG 项目场景。

## 🧭 本模块结构约定

每题带元数据行（归属模块 / 优先级 / 性质 / 来源），正文三段式：

- **简要回答**：面试第一分钟的口头版本，先给结论；
- **详细解析**：2~3 个追问层次的展开，多数题含「在项目里怎样回答」小节，把八股接回自己系统的真实设计；
- **面试总结**：可背诵的回答骨架。

## 📌 与其他模块的关系

- **Python / FastAPI 应用层不在此模块重复收录**：GIL、asyncio、事件循环、生成器、类型注解、FastAPI Depends / StreamingResponse、GC 等题见 08 模块 PY 系列（PY-01~PY-14），本模块 BE 系列是其向部署与数据库方向的延伸。
- **实现口径冲突时以 09 模块为准**（09 模拟面试实录经过最新源码复核）；已核对本模块 31 道抽取题与 09 模块无口径冲突。
- 新撰题正文中「衔接 07/T-E-06」等标注指题库其他模块对应题，可跳转成串。
